# Flavors Kitchen – Interactive Prototype

## Overview

Flavors Kitchen is a restaurant mobile app prototype designed to provide a simple and smooth food ordering experience. 
This project was created to practice UI/UX design principles, interactive prototyping, and user flow design using Figma.

## Objective

The goal of this project was to transform wireframes into an interactive prototype and simulate real app interactions through 
navigation, transitions, and user testing.

## Tools Used

- Figma
- Figma Prototype Mode

## Screens

- Welcome Screen
- Home Screen
- Food Details Screen
- Cart Screen
- Order Details Screen

## Prototype Flow

Welcome → Home → Food Details → Cart → Order Details

## Features

- Clickable navigation
- Interactive buttons
- Smooth transitions
- Mobile-friendly design
- Simple ordering workflow

## User Testing

A few users tested the prototype by navigating through the ordering process. 
Their feedback helped identify small improvements in navigation and button visibility.

## Improvements Made

- Improved spacing and alignment
- Enhanced button visibility
- Added smoother transitions
- Refined overall user flow

## Learning Outcomes

Through this project, I learned:

- Interactive prototyping in Figma
- Creating user-friendly navigation flows
- Basic usability testing
- Improving designs based on feedback

## Outcome

Successfully designed and tested an interactive restaurant app prototype that demonstrates
a complete food ordering journey and essential UI/UX design practices.
